# Vela Shootz

Premier on-demand photography platform connecting clients with verified professional photographers. Experience instant bookings, transparent pricing, 24-48 hour rush delivery, and high-definition curated galleries.

## 🚀 Features

- **Instant Photographer Booking**: Fast, hassle-free scheduling with vetted photographers.
- **Dynamic Pricing & Packages**: Flexible options for portraits, weddings, corporate events, and commercial shoots.
- **Interactive Portfolio & Visual Showcase**: Curated photography samples across diverse genres.
- **Smart Matching**: Connect with local specialists tailored to your specific style and event.
- **Fast Turnaround**: Professional editing and digital gallery delivery within 24–48 hours.

## 🛠️ Tech Stack

- **React 19**
- **Vite**
- **Lucide Icons**
- **Canvas Confetti**
- **Vanilla CSS (Modern Design System)**

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
